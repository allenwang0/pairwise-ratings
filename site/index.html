Setup

Every run hides a true ranking, then scores how well it is recovered#

Each run draws 32 players with hidden skills, then plays 1,280 simulated matches. A rating system sees only who won, and every 10 matches its ranking is scored against the hidden one with Kendall τ: the share of player pairs in the right order minus the share in the wrong order, so 1 is a perfect ranking and 0 is chance.[E2]

Rating systems

Bradley–Terry recovers the hidden ranking most accurately#

Elo nudges two ratings after each match by a fixed step. Glicko-2 also tracks how uncertain each rating is and moves uncertain ratings further. Bradley–Terry refits every skill by maximum likelihood on all matches so far, so early results are not forgotten — consistent with its lead, though the simulation also hands it the exact outcome model.

Pair selection

Information-gain pairing ends more accurate, but not detectably sooner#

Information gain picks the pair whose result would shrink Glicko-2's total uncertainty the most; for Glicko-2 that amount is known before the match is played.[E7] Pairing the least-known player against a random opponent, or the two closest-rated players, sounds reasonable but leaves more runs short of the target than random pairing.

Where the mean τ curve first crosses 0.8 is a fragile summary: random pairing's mean stays between 0.795 and 0.805 from 870 to 1,050 comparisons, so a tiny change in the mean moves that crossing by hundreds of comparisons. The per-run medians above do not have that problem.

Correctness

Glicko-2 reproduces Glickman's worked example#

Glicko-2 is written from Glickman's paper and checked against its worked example: a 1500-rated player (RD 200, volatility 0.06, system constant 0.5) beats a 1400 and loses to a 1550 and a 1700. The code matches the printed values to within 0.01 rating points; the paper rounds its intermediate steps.[E6]

Limitations

Results hold for simulated players with fixed skills#

  • Simulated, correctly specified data. Outcomes follow the Bradley–Terry model, which favours the Bradley–Terry fit; real comparisons are noisier.
  • Fixed skills. No player improves or declines, so tracking changing skill is untested.
  • One pool size. Only 32 players; the value of smart pairing depends on pool size.
  • Pair rules use Glicko-2 only. Information gain and the other rules need Glicko-2's deviations; they were not combined with Bradley–Terry.
  • One accuracy target. Time-to-target results are for τ 0.8; other targets were not run.

Reproduce

Reproduce it in four commands#

Commands run from a clone of allenwang0/pairwise-ratings.

  1. Install the pinned dependencies (needs uv and make).

    make setup

  2. Run the tests, including the Glicko-2 worked example and the report checks.

    make test

  3. Run every condition over 100 seeds and write results/results.json.

    make results

  4. Rebuild this page and the README block from the results.

    make report
